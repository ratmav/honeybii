# scaffold honiipy cli

feat. make the package runnable end to end: a cli that prints help and version,
nothing ported yet. this is the inside-out starting point everything else
consumes.

## decide

- cli framework: typer (osai) or argparse (sylvan). both are in-house
  precedent. pick one and record why in `docs/conventions.md`.

## what changes

- `python/honiipy/pyproject.toml` — add the cli dep (typer if chosen) and
  `[project.scripts] honiipy = "honiipy.cli:main"`.
- `source/honiipy/cli.py` — entrypoint. `main()` calls the app, help on no args,
  banner on `--help` (osai `BannerGroup` pattern if typer).
- `source/honiipy/_banner.py` — placeholder ascii (the python snake comes later,
  generated by honiipy itself).
- `tests/test_cli.py` — assert help and version work.

## verify

`cd python && uv sync`, then `uv run honiipy --help` and `uv run pytest`.

## deliverable

`uv run honiipy` runs and prints help; first test green.
