# license

docs. add honiipy's license, carried forward from honeybii's original.

## context

honeybii is mit-licensed (`honeybii.gemspec`: `s.license = 'MIT'`, author jamey
deorio) but ships no `LICENSE` file. honiipy is a port, so it carries the same
mit license forward — same license, lineage preserved.

## what changes

- add `LICENSE` (mit) at the repo root.
- preserve the original copyright holder: jamey deorio (the honeybii author).
  look up the original year from honeybii.com / the upstream repo if available;
  keep the original holder either way.
- add the honiipy maintainer's copyright line alongside the original.

## deliverable

`LICENSE` present, mit, crediting both the original honeybii author and the
honiipy maintainer.
